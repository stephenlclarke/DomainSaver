# dev-wrapper.txt - names for ONE domain that fronts MANY short-lived projects.
#
# The use case: you want a single home like shed.link, and every weekend
# experiment becomes rss.shed.link, tally.shed.link, whatever.shed.link. So the
# name has to (a) be short, because it is a prefix everything else hangs off,
# (b) survive being said out loud, and (c) imply "workshop", not "product" -
# nothing here should sound like it promises uptime.
#
# Used with generate.sh:
#   ./scripts/generate.sh --words wordlists/dev-wrapper.txt --tlds link,dev,sh
#
# Format: one label per line, lowercase a-z 0-9 and hyphen. '#' starts a
# comment, to end of line. No dots - these are labels, not domains.
#
# CAUTION: the short, obvious ones (shed, lab, forge) are exactly the names a
# registry marks premium. shed.link looked unregistered and quoted at $819.27
# against a $7.72 list price. Expect to price-check, not just availability-check.
