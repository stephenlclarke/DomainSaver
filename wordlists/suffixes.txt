# suffixes.txt - short words that go AFTER a name you already want.
#
# A suffix usually reads better than a prefix (shedworks beats worksshed) and
# survives being said aloud without a hyphen. Mostly place-and-container nouns,
# because they compose with almost any head word.
#
# TWO TRAPS worth knowing before you use this list:
#  1. Do not pick a suffix that duplicates your TLD. shedapp.app, shedlab.lab
#     and shedhq.hq read as stutters and get misremembered as the shorter form.
#  2. Suffixes that are themselves TLDs (app, dev, io, sh, ly, co, one, now)
#     tempt you into a domain hack (she.dshed - no). Keep the whole word in the
#     label unless the hack is genuinely readable.
#
# Used with generate.sh:
#   ./scripts/generate.sh --affix shed --suffixes wordlists/suffixes.txt --tlds com
#   ./scripts/generate.sh --affix shed --prefixes wordlists/prefixes.txt \
#       --suffixes wordlists/suffixes.txt --tlds dev --affix-both
#
# Format: one label per line, lowercase a-z 0-9 and hyphen. '#' starts a
# comment, to end of line. No dots - these are labels, not domains.
